## 为什么是文献级卡

该文是「有红移 GRB 的最大光学测光汇编」（64813 点 / 535 暴），逐暴机读表在 MNRAS 在线补充材料 /
GitHub 仓库 SLAC-Gamma-Rays/grbLC（`grblc/data/mag_files/<YYMMDD[字母]>_mag.txt`，制表符 9 列：
time_sec / mag / mag_err / band / system / telescope / extcorr / source(GCN 号或文献号) / flag）。
本库大量 lc 行由 bot 以 `Dainotti2024;NNNNN` 形式转引自该表。经 GRB141028A 审验（2026-10-27）：
该表绝大多数行是 **GCN 通告的转引**（source 列直接给 GCN 号），且存在时间锚点失真
（把通告里的口语相对时长或错误历元当 time，如 141028A 的 28800 s / 151488 s 两例）与
星等系统标注的非受控取值：该表 system 列直接用 Johnson / SDSS / Lupton / Vega / AB 等混合记法（141028A 里 16993 给 Vega、17030/17035 给 **Lupton**、16972 给 Johnson、16985 给 SDSS）。**失真发生在本库导入管线**：存量行把 Lupton/SDSS 映射成了 Vega/AB（HEAD 的 106272.0/187773.0/26766.9 三行带 Vega），而 Dainotti 表本身没错；接手时应回到通告原文判读，原文未声明系统就留空。
因此按增量门槛，该文对任何库内源都**不构成源级卡理由**：数值与 GCN 同源、可直接检索，
且口径不可盲信——接手任何源时一律回到通告原文逐值核对。
